# Meu Portfólio

Esse projeto é uma forma simples (e diferente) que encontrei de me apresentar.

Mais do que um portfólio tradicional, ele representa como eu penso, como eu construo e como eu estou evoluindo como desenvolvedora.

## Sobre

Sou desenvolvedora Full Stack em formação, com foco em criar soluções funcionais e bem construídas — do back-end ao front.

Esse projeto foi feito com HTML, CSS e um pouco de criatividade pra transformar uma apresentação em algo mais interessante.

## Tecnologias

- HTML
- CSS

## Objetivo

Explorar ideias, testar abordagens e construir algo que represente mais do que só código — mas também a forma como eu aprendo e evoluo.
